
# CE318 SMP Reader

Скрипт для чтения данных с трёхфазного счётчика **CE318** по протоколу **SMP** поверх TCP (через `ser2net`).

Читает:
- накопленную активную энергию A+ (кВт·ч);
- мгновенные значения по фазам A/B/C: ток, напряжение, полную/активную/реактивную мощность;
- суммарные мощности (P, Q, S — с векторным расчётом S).

## Возможности

- Работа по TCP (например, через `ser2net` на последовательном порту счётчика).
- Проверка CRC16 каждого кадра.
- Экранирование/деэкранирование байт-стаффингом (`0xC0`, `0xDB`).
- Декодирование чисел в формате DFF (7 бит на байт, с поддержкой знаковых значений).
- Вывод в виде JSON (по умолчанию) или человекочитаемой таблицы.
- Режим `--raw` для просмотра сырых hex-дампов запросов и ответов.

## Требования

- Python 3.10+
- Счётчик CE318, доступный по TCP (у меня оптопорт < EASYESP <`ser2net`)
- Внешних зависимостей нет — только стандартная библиотека.

## Установка

```bash
git clone https://github.com/<ваш-логин>/ce318-smp-reader.git
cd ce318-smp-reader
```

## Использование

```bash
# JSON на stdout (по умолчанию)
python ce318_smp_reader.py --host 192.168.1.123 --port 1234

# Красивая таблица
python ce318_smp_reader.py --host 192.168.1.123 --port 1234 --table

# С дампом сырых байт (в stderr)
python ce318_smp_reader.py --host 192.168.1.123 --port 1234 --raw

# С конкретным сетевым адресом счётчика
python ce318_smp_reader.py --host 192.168.1.123 --port 1234 --addr 0x00000001
```

### Аргументы

| Аргумент        | По умолчанию     | Описание                                 |
---------------------------------------------------------------------------------
| `-h,--help`     |                  | справка по аргументам                    |
| `--host`        | `192.168.1.123`  | IP-адрес ser2net                         |
| `--port`        | `1234`           | TCP-порт                                 |
| `--addr`        | `0`              | Сетевой адрес счётчика (`0` — broadcast) |
| `-t`, `--table` |                  | Вывод таблицей вместо JSON               |
| `-r`, `--raw`   |                  | Дамп сырых байт (stderr)                 |
| `-d`, `--debug` |                  | Отладочные сообщения                     |

## Как устроен протокол

2. **Кадр** ограничен байтом `0xC0`.
3. **Байт-стаффинг**: `0xC0` → `DB DC`, `0xDB` → `DB DD`.
4. **CRC16** (полином `0x8005`, init `0`) — в конце кадра, старший байт вперёд.
5. **DFF** — числа переменной длины, 7 бит на байт, старший бит = «продолжение».

## Ограничения

- Тестировалось только на CE318 .
- Мгновенные значения читаются тремя отдельными запросами (энергия / фазы / суммарные мощности).
